# Nero-snake-
A production-quality, self-learning Snake AI built in PyTorch using Double Dueling DQN, Prioritized Experience Replay (PER), N-step returns, and an interactive Pygame UI. 


Neuro-Snake AI is a high-performance, autonomous Snake game environment and training framework powered by PyTorch and Pygame.

Built from the ground up to demonstrate modern Deep Reinforcement Learning techniques, the agent learns optimal navigation strategies through an egocentric state representation without hardcoded heuristics.
